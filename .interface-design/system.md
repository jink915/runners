# 러너스 예배 — 디자인 시스템

## 방향
- 사람: 주일 예배를 준비하는 러너스 운영자·사회자. 대부분 휴대폰으로, 예배 직전이나 주중 틈틈이 연다.
- 할 일: 다음 주일 담당자 확인 → 빈 자리 배정 → 사회 원고 복사.
- 느낌: 러너스 포스터처럼 맑은 하늘색, 친근한 양 캐릭터, 하지만 정보는 또렷하게.
- 시그니처: '다음 주일' 카드 뒤에서 내다보는 하트 양 + 반짝이 별.

## 색 (토큰은 style.css :root)
- 배경 #EEF5FB(하늘빛 흰색) / 카드 #FFFFFF / 입력·눌림 #E4ECF6 / 글자 #13213F(남색)
- 강조 #2C6FC2 한 가지만. 의미 색(ok/warn/bad)은 상태 표시에만.
- 히어로만 하늘 그라데이션(#A9DCF7→#E6F5FE). 다크: 남색 #0A1120 바탕, 강조 #7DB4F2.

## 타입
- IBM Plex Sans KR. 큰 제목 30/700(-0.025em), 섹션 라벨 13/600 muted, 본문 15/400, 보조 13 muted.
- 숫자(날짜·찬송·순위)는 tabular-nums. 제목 balance, 본문 pretty.

## 간격·모양
- 4px 단위. 카드 안쪽 16px, 섹션 사이 24px.
- 둥글기: 카드 20 / 안쪽 요소 12 / 조작 10 / 히어로 28 / 시트 24.
- 깊이: 그림자 고리(--shadow-border) 하나로 통일, 구분선만 1px --line.

## 컴포넌트
- 행(row): 최소 60px, 왼쪽 날짜 상자(월 11 / 일 20 bold), 오른쪽 칩 + 꺾쇠.
- 버튼: 40px(작은 것 34px + 44px 터치 영역), 누르면 scale .96 / 150ms.
- 세그먼트: 회색 홈 안에 흰 선택 칸.
- 시트: 휴대폰은 아래에서 420ms drawer 곡선, 손잡이를 끌어 닫기(30% 또는 0.5px/ms). 데스크톱은 가운데 창 200ms.
- 삭제는 시트 하단에서 확인 단계(취소 / 빨간 실행)를 거친다.
- 양: heart=홈 히어로·아이콘, pray=원고·불러오기, wave=환영·빈 화면.
